Controls & saving

Drag to paint. Right-click to pick terrain. Hold Space or the middle mouse button to pan. Ctrl + wheel zooms. B/R/F/E/I/H switch tools. Ctrl+Z undoes; Ctrl+Shift+Z redoes.

Terrain joins and water/wall borders update automatically. Props and monsters snap to the grid. Erase removes the top editable item on the active palette. Stairs, portals, town services and raised cliff structures are fixed landmarks. Switch to the upper floor to paint plateau tops.

Drafts save in this browser. Export saves a version-2 JSON file; it does not publish the live map. Replace packages/game-data/src/grid-overrides.json, run checks, and deploy the client and server together.

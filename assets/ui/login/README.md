# Entry screen artwork

- `Realm of Shadows Login Screen.png`: original supplied portrait artwork, retained.
- `realm-of-shadows-logo.png`: transparent isolated rendition of the original logo.
- `realm-entry-background.webp`: clean landscape background matching the supplied
  world artwork, with the old baked-in text and controls removed.

The logo and backdrop are shared by three responsive full-screen entry views:
login, character selection, and character creation. Real HTML fields/buttons sit
above the scene; no click regions depend on the dimensions of a flattened image.
Character previews use the existing outfit preview assets, not new character art.

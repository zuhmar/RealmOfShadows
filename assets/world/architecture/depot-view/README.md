# Depot projection benchmark

Generated by `npm run art:depot-view` from the existing code-native wall materials and purpose-drawn furniture geometry. PNGs live in `assets/world/objects/house-depot-*`; these SVGs are the editable sources.

The grid stays square. An 80px wall rise moves its upper edge 16px left. Successive stories share their projected edge; roof tiles are shifted by the complete rise. Front wall and door images include a 16px transparent gutter, while east walls include a full side plane connecting the upper edge to the unchanged ground boundary. Short end panels have separate native-size frames rather than compressed full panels. West walls keep their top-cap profile.

Nearby modular counters/tables/benches/shelves use parallelogram tops, front faces and an exposed right end. Connected pieces share the same edge. Existing sprites for the surrounding scenery retain their native artwork.

This benchmark applies only to the Depot shell and nearby modular furnishings. Other building geometry, grid collision, floor connections, Depot storage, windows and character saves are unchanged. The door hit area includes the sprite gutter so it follows the visible opening.

Validation: `tests/depot-view.test.ts`, `tests/browser-depot-view.cjs`, `tests/browser-house-joins.cjs`, and the root unit/build checks. The browser benchmark exports desktop/mobile interior/exterior screenshots under `/tmp/depot-view-*`.

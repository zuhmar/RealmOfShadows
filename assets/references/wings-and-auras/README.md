# Wing and aura references

Upload the combined reference sheet here as `wings-and-auras.png`.
If wings and auras are on separate sheets, use `wings.png` and `auras.png`.
Each image can contain multiple designs.

Identify designs by their names or by sheet, row and column. These are art
references, not runtime assets; wings and auras remain separate wearable
cosmetics when implemented in the game.
